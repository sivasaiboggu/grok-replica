Replies come from Google Gemini. Paste your own free API key — it is stored only in this browser, never sent anywhere except to Google's API.

Get a free key at Google AI Studio. If the key is wrong, the app says so plainly instead of inventing an answer.

If a model is unavailable for your key, the error from Google is shown as-is.

About this app. Grok Replica is a study clone built to learn how a minimal chat app is put together. It is not Grok, not xAI, and not affiliated with either. The name and the dark, minimal look are a nod to grok.com — the code, the words and the replies are this project's own.

Nothing you type leaves this browser except the messages you send to Google Gemini, using your key. Chats live in this browser's local storage. Erasing them removes them for good.
